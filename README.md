MediaFetcher

MediaFetcher is a lightweight, high-performance Android application designed to download video and audio content directly from YouTube. Built with Kotlin and powered by the robust youtube-dl-android library, it provides a seamless mobile experience for offline media management.

🚀 Features

Video Downloads: Fetch high-quality MP4 videos.

Audio Extraction: Convert YouTube videos directly to MP3 files with a single tap.

Real-time Progress: Integrated progress bar to track download status.

Mobile Optimized: Automatically selects the best formats for Android compatibility.

Storage Management: Organizes downloads into a dedicated "my_videos" folder or the system Downloads directory.

🛠️ Built With

Kotlin - Modern Android development language.

youtube-dl-android - The core engine for video processing.

FFmpeg - Used for high-quality audio extraction and video merging.

Coroutines - Ensures smooth UI performance by handling downloads in the background.

📲 How to Use

Paste a YouTube URL into the input field.

Choose your format (Video or Audio).

Tap Download Now.

Find your files in your device's Downloads folder.
